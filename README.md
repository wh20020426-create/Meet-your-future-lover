# Soulmate Lab · 灵犀实验室

M1 可运行的移动优先网站，按最新产品方向采用 **本地规则人物档案 + 60 张预制肖像图库**。网站运行时不调用 AI，不需要 API 密钥，不收费、不购买域名、不公开部署。

## 我不懂编程，怎么打开？

本次交付已在当前电脑安装好依赖并完成构建。双击项目内的 **启动网站.cmd**，等待自动打开浏览器。网站地址为：

**http://127.0.0.1:3000/**

下次体验仍然双击同一个文件。关闭网页不会删除答题进度。需要停止后台服务时，双击 **停止网站.cmd**。

如果开发预览已经在运行，启动器会直接打开现有网站。启动失败的记录保存在 `data/server.log`。

## 建议的体验顺序

1. 首页点击「开启我的心动实验」，完成成年确认。
2. 回答 25 道题；年龄段和伴侣性别呈现为必要项，其他可以跳过。
3. 可以随时返回上一题、刷新继续；核心题完成后可补充 10 项生活细节。
4. 创建档案，查看人物照片、五维评分、答案解释、日常、摩擦点与故事。
5. 进入「完整人物档案」，查看身份、成长、性格与关系观。
6. 打开海报，选择纸张颜色、可选昵称，下载 1080 × 1680 PNG。
7. 在关于页面管理数据，或在结果页删除单个结果。

首页也有无需答题的示例和图库入口。

## 图库如何工作

- 60 张独立生成的成年虚构肖像，覆盖男性、女性、中性呈现。
- 5 个年龄段：18–22、23–27、28–34、35–44、45–60 岁。
- 每个组合有清爽自然、干练知性、阳光活力、文艺温柔 4 种气质。
- 先限制成年年龄与性别，再优先匹配气质、兼顾穿搭，用确定性种子稳定选择。
- 文字档案采用选中图片的穿搭、发型与气质标签。年龄是虚构设定，图片按年龄段匹配。
- 图库数量固定，不同用户可能看到相同肖像。性格、职业、生活与解释仍来自问卷规则。
- 图片用内置 ImageGen 一次性制作，**运行时没有 AI 接口**。最终使用的提示词集在 `IMAGE_PROMPTS.json`，标签目录在 `lib/library-manifest.json`，素材在 `public/library/`。
- 网页与海报明确标注虚构和合成内容，WebP/PNG 另附描述性说明元数据。

图库浏览页：**http://127.0.0.1:3000/library**

## 本地分享的范围

匿名链接与二维码只在当前电脑的本地服务运行时有效。没有公开托管，朋友的手机无法用 `127.0.0.1` 打开这台电脑的网站。可以把已下载的海报图片自行分享。此版本未开放局域网访问。

分享页只包含人物摘要，不包含用户原始答案、偏好特征、评分解释或海报昵称。删除结果后分享 token 同时失效。

## 数据存储

- 问卷草稿：浏览器 `localStorage`，键为 `sl_draft`；成年确认也保存在本次会话/草稿中。
- 匿名管理权限：HttpOnly、SameSite=Strict 随机会话 Cookie，30 天。
- 结果：本机 `data/results.json`，不保存原始问卷对象，但包含生成所需的偏好特征以及可能引用答案的解释。
- 过期结果：30 天后，在下一次本地数据操作时清理。
- 海报昵称：仅当前页面用于绘图，不写入服务器。
- 没有跟踪器、统计埋点或外部字体。服务只监听 `127.0.0.1`。

请先在关于页面删除不需要的结果，再清除浏览器 Cookie。若 Cookie 丢失，原匿名结果不再能由这个浏览器管理；设备所有者可关闭网站后删除项目的 `data` 文件夹，移除全部本机结果。

## 技术结构

Next.js App Router + React + TypeScript；CSS 响应式样式；Zod 输入与人物 Schema；Node 文件存储；Canvas 与本地二维码绘制海报。

```text
app/                 首页、问卷、增强、生成、结果、详情、海报、图库、说明与 API
components/          页面交互和复用组件
lib/questions.ts     25 道核心题、10 道可选增强题
lib/schema.ts        问卷输入、人物档案、公开投影数据结构
lib/engine.ts        画像提取、约束、模板、评分与解释
lib/library.ts       静态图库匹配
lib/library-manifest.json  60 张图片的标签目录
lib/store.ts         串行事务、原子写入、过期清理
lib/api.ts           匿名会话、同源校验、请求大小与限流
lib/poster.ts        PNG 海报与合成说明元数据
public/library/      随项目交付的 60 张 WebP 图片
scripts/             启动、停止、素材优化
tests/               模型单元测试与 HTTP 端到端测试
```

## API

| 方法与路径                    | 行为                                     |
| ----------------------------- | ---------------------------------------- |
| GET `/api/health`             | 本地服务状态、图库数量、无付费接口声明   |
| POST `/api/results`           | 校验成年人和问卷、按幂等键创建或复用结果 |
| GET `/api/results/:id`        | 只向创建该结果的匿名会话返回完整档案     |
| DELETE `/api/results/:id`     | 删除本人结果并撤销分享                   |
| DELETE `/api/results`         | 删除当前匿名会话的所有结果               |
| POST `/api/results/:id/share` | 主动创建或复用随机匿名分享 token         |
| GET `/api/share/:token`       | 只返回精简人物公开投影                   |

没有实时生图、模型调用或付款接口。每匿名会话每小时最多新建 10 份结果，本地服务总计每小时 100 份；读取与复用不消耗新建额度。当前限流保存在进程内，重启后重置，面向单机原型使用。

## 评分口径

基准权重依次为关系价值观 30、沟通冲突 25、生活方式 20、现实条件 15、审美 10。第 6 题会将审美权重微调至约 7.3–12.7，其余权重同比例缩放，合计 100。总分为分项加权平均四舍五入。所有权重和得分是透明的产品规则，不能解释为心理诊断、科学预测或现实匹配成功概率。

跳过项使用中性默认值，答案解释只引用实际回答的题目。完整逻辑在 `lib/engine.ts`，测试会检验公式与确定性。

## 换一台电脑 / 开发者操作

需要 Node.js 22 或更新版本。复制源码后，在项目目录运行：

```sh
npm ci
npm run build
npm start
```

开发模式：`npm run dev`。无须创建 `.env`；`.env.example` 只有可选本机存储设置。

如果 npm 官方仓库在当前网络不可达，可用 `npm ci --registry=https://registry.npmmirror.com` 安装公开依赖；本次安装使用了该镜像，版本由 `package-lock.json` 锁定。

## 测试

```sh
npm run typecheck
npm test
npm run verify:assets
npm run build
```

启动本地网站后，另开终端执行：

```sh
npm run test:api
```

API 测试使用自行创建的匿名测试会话，完成后删除该会话的测试结果；不会操作其他浏览器的结果。浏览器验收与最新结果见 `TEST_REPORT.md`。

## 当前边界

这是单机原型，未包含公网部署、数据库集群、用户登录、聊天、付款或运营后台。真人匹配和未来预测均不在产品范围内。按照最新方向，不再预留真实 AI 服务接入作为下一步。

后续可继续增加图库、调整规则和人物文本、改进个性化反馈。任何公开部署、付费资源或费用都需另外授权。
